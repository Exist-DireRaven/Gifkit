# 第二阶段第三步：提取 Mimo 配置

日期：2026-09-13（基于第二步拆开入口之上的增量改动）

## 目标与验收

目标：帧序、网格、锚点、停顿、补帧数量从代码迁入案例配置；明确空帧、超大帧、裁切、缩放策略。

验收标准（已达成）：
- **换素材无需修改核心算法**：新建一份案例 JSON 指向新素材，五个构建入口即可完整运行——由合成素材的端到端测试证明（v1 整流程、v2 含光流的整流程，全部只靠配置文件驱动）。
- 构建产物与配置抽取前**逐字节同尺寸**（见下方证据），人工艺术选择（PLAN/NB/HOLD、帧序挑选、停顿）原样保留在配置里而非被删除。

## 案例配置（cases/）

五份配置对应五个构建入口；相对路径一律相对配置文件所在目录解析：

| 配置 | 入口 | 迁出的 Mimo 参数 |
|---|---|---|
| `mimo_v1.json` | `make_gif.py` | 源图、格子框文件、4×4 网格、画布 352、基线 332、帧时长 200 ms、透明阈值、小图尺寸、输出名 `mimo_loop` |
| `mimo_v2_key.json` | `v2/build_gifs.py` | 关键帧目录/命名模式/数量、16 组转场的 PLAN（停顿+中割相位/来源/时长） |
| `mimo_v2_24fps.json` | `v2/build_24fps.py` | 每转场中割数 NB、关键帧停顿 HOLD、24 fps、四档输出（名称/透明/缩放） |
| `mimo_v3.json` | `v3/build_gifs_v3.py` | 每块中割数、每序列的 intro 停顿/块列表/块收尾停顿（含枪口闪光 +150 ms）、settle 桥接 |
| `mimo_v4.json` | `v3/build_melee_v4.py` | 瓦片目录与块号、画布/基线/目标身高/放大上限、出拳/旋身帧序、桥接相位、自适应插入阈值、各停顿 |

CLI 约定（五个构建入口一致）：

```bash
python make_gif.py --config cases/mimo_v1.json            # --config 缺省即用捆绑案例
python v2/build_24fps.py --config my.json --frames-dir k/  # 输入目录可用 CLI 覆盖配置
python v3/build_melee_v4.py --out path/to/dir              # 输出目录显式指定；必须为空或不存在
```

- `--out` 缺省时行为不变：新建 `runs/<prefix>-<id>/` 独立目录。
- `--out` 指向**已存在且非空**的目录会被拒绝（防止覆盖），错误信息明确。
- 构建入口增加 `--no-tween-pngs`（跳过中割预览 PNG）。

## 材质边界策略（显式化，默认报错不猜）

| 情形 | 策略 | 实现 |
|---|---|---|
| 网格格子缺框 / 框越界 / 裁片全透明 | **报错**，错误信息含格子号与具体数值 | `make_gif.cut_frames()` |
| 裁片大于画布 | 配置 `oversize_policy`: `clamp`（裁到画布边，历史行为）/ `error` | 同上；**顺带修复了第一阶段审查发现的"超大裁片粘贴数组尺寸不匹配"崩溃 bug**——原 clamp 路径实际会崩 |
| 关键帧文件缺失 / 关键帧全透明 | **报错**，含路径 | v2 两个构建的 `load_keys()` |
| 配置 PLAN/NB/HOLD 与关键帧数量不匹配 | **报错**，列出缺失项 | v2 两个构建 |
| 对齐帧数不是块长整数倍 / 对齐帧全透明 | **报错** | `v3/build_gifs_v3.load_aligned()` |
| 瓦片缺失 / 瓦片无墨迹 / 中位身高为 0 / 放置目标无像素 | **报错**，含路径 | `v3/build_melee_v4.load_tile()/place()` 等 |

原则与产品方向一致：默认只检测报告、不自动修复；修复类能力留待显式启用。缩放策略本身（v4 的目标身高 + 放大上限、逐块尺度归一）属于算法，参数在配置里。

## 其他改动

- `v2/morph.py`：`load_key`/`get_flow` 增加 `pattern` 参数，支持非 `key_NN.png` 命名的素材目录；缓存键仍按帧内容摘要，不受命名影响。
- v3 输出清单文件 `_v3_plan.json` 格式改为 `{tag: {labels, durs}}`（原为平铺四键）——属每次运行新生成的产物，不影响任何历史文件。
- **12 个一次性工具脚本收编为 import 安全**（顶层只有常量与纯函数，管线在 `main()`）：`segment.py`、`build_frames.py`、`v2/segment.py`、`v2/align.py`、`v2/strip24.py`、`v2/export_key02_11.py`、`v2/make_chart.py`、`v2/export_crops.py`、`v3/build_v3.py`、`v3/extract_all.py`、`v3/locate_sprites.py`、`v3/strip_blocks.py`。其中部分加了最小的 `--source/--out-dir/--tiles-dir` 类参数。它们的网格/分镜布局假设（4×4、GPT 排版、MIN_AREA 等）仍是 Mimo 特例——**配置化留给第五步"第二套素材"实际需要时再做**，此处只保证导入无副作用与基础可用。
- 至此**全部 26 个入口/工具脚本导入均无副作用**，由测试逐个强制（`tests/test_cli_io.py` 的 26 项参数化用例）。
