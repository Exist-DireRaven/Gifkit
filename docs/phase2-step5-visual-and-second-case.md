## 3. 第二套素材：walker（ walkers 与 Mimo 零共同参数）

`examples/walker/`：完全程序化生成的步行角色（确定性、无授权问题、可公开），
3×4 网格（非 4×4）、160px 格子（非 313px）、白底瓦片（非透明底）、12 fps 步行（非 24 fps 格斗）。

- 网格路径：`gifkit build --case walker_grid` → 12 帧步行循环（4 个 GIF）。
- 瓦片路径：`make_material.py` → `build_v3.py --tiles-count 16 --canvas 320 320 --baseline 296 --target-height 180`（对齐器本轮参数化）→ `gifkit build --case walker_loop` → 9 帧 @12fps。
- 深色背景目检：边缘干净（硬边像素无镶边）、步态/摆臂正确、地线稳定；封闭白底楔形见上述已知局限。
- 意义：**"换素材无需修改核心算法"从测试断言变成真实演示**——两份新案例配置 + 一条生成命令，零代码改动。真正的真实世界异质素材仍欢迎用户提供后走同一路径。
