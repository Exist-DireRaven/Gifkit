## v1 处理方式

1. **分割**：用 alpha 通道做连通域分析（`scipy.ndimage.label`），按质心把 65 个
   连通块归入 16 个格子，取每格所有块并集的包围盒 —— 因此动作特效（刀光、
   尘土、速度线、闪光）不会被裁掉。
2. **对齐**：水平方向用「模糊 alpha 的平方质心」做锚点，让角色本体始终居中
   （避免右侧刀光把角色挤到一边）；垂直方向把每格包围盒底边压在统一的
   地平线 y=332 上，站姿踩地、跳跃/浮空姿势自然悬空。
3. **配色**：把 16 帧拼成一张大图后统一量化出 254 色调色板，再让每帧映射到
   同一调色板，避免逐帧量化导致的闪烁。透明版用索引 0 作为透明色并设
   disposal=2，防止残影。

## 历史的重新生成 / 调整方式（已被案例配置取代）

当年的工作流是直接改脚本顶部常量（`NB`/`HOLD`/`DURATION`/`CW`/`BASELINE`/
`ALPHA_SOLID` 等）。现在这些参数都在 `cases/mimo_*.json` 里；重建命令见
README 快速开始。历史脚本（`segment.py`、`v2/align.py` 等）仍保留，作为
"从原图到关键帧"的准备工具。
